# Nasus 工作空间与页面承载面

## 1. 说明

本目录描述的是 **工作空间 / 页面承载面**，不是产品一级模块。

它回答的问题是：

- 哪些工作空间存在
- 每个工作空间承载哪些产品能力
- 用户如何在空间之间下钻

## 2. 与其他目录的关系

- [产品模块地图](../product-modules.md)：定义产品一级能力模块
- `design/spaces`：定义这些能力落在哪些工作空间里
- `frontend / backend / platform`：定义这些工作空间和能力如何被实现
